# Post-Build GitHub Push & Vercel Deployment Verification Rule

- **Automatic Git Commit & Push**:
  - Whenever code changes or feature implementations are completed, Antigravity must stage all files (`git add .`), create a descriptive commit (`git commit -m "..."`), and push to GitHub (`git push`).
- **Vercel Deployment Verification**:
  - Check for any build or deployment errors and ensure zero syntax/type errors before reporting completion.
- **Language Directive**:
  - All communication, task walkthroughs, and technical explanations must strictly be presented in Bengali (বাংলা).
